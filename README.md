# رادار سهم

رادار سهم یک داشبورد فارسی برای غربالگری اولیه شرکت‌های بورسی است. این ابزار رشد فروش، کیفیت جریان نقد، سهم بازار و جذابیت ارزش‌گذاری را کنار هم نمایش می‌دهد تا شرکت‌های مناسب برای بررسی عمیق‌تر سریع‌تر پیدا شوند.

## پیش‌نیاز

- Node.js نسخه `22.13.0` یا بالاتر
- فایل `.env` در ریشه پروژه برای تنظیمات محیطی، در صورت نیاز

## نصب و اجرا

```bash
npm run install:ci   # نصب وابستگی‌ها
npm run dev          # اجرای محیط توسعه
```

پس از اجرای دستور توسعه، آدرس نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید. برای انتخاب پورت دیگر:

```bash
npm run dev -- --port 3000
```

## ساخت و پیش‌نمایش نسخه نهایی

```bash
npm run build        # ساخت نسخه قابل انتشار
npm run start        # اجرای پیش‌نمایش نسخه ساخته‌شده
```

## دستورات کاربردی

```bash
npm run lint         # بررسی خطاهای کد
npm run db:generate  # ساخت migration بعد از تغییر schema دیتابیس
```

کد رابط کاربری در پوشه `app/` قرار دارد. اطلاعات اتصال و متغیرهای محیطی را در `.env` نگه دارید و آن را در مخزن commit نکنید.

## وضعیت داده و بررسی ایمنی

در نسخه فعلی، فهرست شرکت‌ها و امتیازها نمونه هستند و دقت آماری یا سیگنال قابل اتکای سرمایه‌گذاری ارائه نمی‌کنند. گزینه «بررسی اتصال دیتابیس قبل از جست‌وجو» در رابط کاربری به‌صورت پیش‌فرض روشن است؛ در صورت قطعی دیتابیس، جست‌وجو متوقف می‌شود. برای حالت بررسی دستی، این گزینه را خاموش کنید و اطلاعات را در کدال و TSETMC تطبیق دهید.

دکمه «اسکن کل بازار» تا زمان پیکربندی Provider واقعی TSETMC/Codal عمداً رتبه‌بندی تولید نمی‌کند. گزارش بررسی فاز اول در فایل `PHASE1-AUDIT.md` قرار دارد.

صفحه `/data-sources` وضعیت Connectorها، آخرین probe، تازگی، پوشش و خطاهای هر منبع را نمایش می‌دهد. منابعی که کلید یا مجوز لازم دارند فقط بعد از تنظیم Secret مربوط فعال می‌شوند:

صفحه `/learning-assistant` فرهنگ لغت نسخه بندی شده را با توضیح مبتدی و پیشرفته، فرمول، مثال فرضی، محدودیت، ارتباط با رتبه بندی و لینک منبع ارائه می‌کند. علامت `?` کنار اصطلاحات در رابط، توضیح را بدون خروج از صفحه باز می‌کند.

لایه دریافت داده از مسیر `/api/ingestion` روش های هر منبع، provenance، checksum، وضعیت HTTP، retry، اعتبارسنجی قرارداد و ورود JSON/CSV مجاز را مدیریت می‌کند. روش های تاییدنشده یا منابع بدون مجوز خودکار فعال نمی‌شوند و به رتبه بندی داده تزریق نمی‌شوند. جزئیات ماتریس منابع در `DATA-INGESTION-PLAN.md` است.

```bash
FRED_API_KEY=...
TRADING_ECONOMICS_API_KEY=...
```

کلیدها را در فایل‌های commit‌شده قرار ندهید. وضعیت `Active` فقط به معنی موفق‌بودن probe و اعتبارسنجی قرارداد پاسخ است؛ برای رتبه‌بندی، اعتبار داده و تاریخ مؤثر آن نیز باید تأیید شود.

> این ابزار برای غربالگری و بررسی اولیه است و توصیه قطعی خرید یا فروش محسوب نمی‌شود. داده‌ها را قبل از تصمیم نهایی با منابع رسمی مانند کدال و TSETMC تطبیق دهید.
