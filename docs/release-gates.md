# دروازه های انتشار

## Data Integrity Gate

schema، واحد، تاریخ، duplicate، outlier، corporate action و reconciliation باید ثبت و پاس شده باشند.

## Calculation Gate

محاسبه حساس باید آزمون مستقل، نتیجه مورد انتظار، اختلاف و نسخه مدل داشته باشد.

## Ranking Gate

Snapshot باید کامل باشد، حداکثر ۱۰۰ نماد واجد شرایط داشته باشد، Watchlist اثر اضافی نداشته باشد و علت هر رتبه قابل ردیابی باشد.

## Backtest Gate

بدون look-ahead و survivorship bias، با هزینه و محدودیت اجرا و گزارش out-of-sample.

## Risk Gate

تمرکز صنعت، نقدشوندگی، توقف، خروج و ریسک های ناشناخته باید نمایش داده شوند.

## Operational Gate

Job پایدار، progress واقعی، retry/cancel، idempotency، audit log و حفظ snapshot قبلی در شکست.

تا پاس شدن این دروازه ها، رتبه بندی برای تصمیم سرمایه واقعی منتشر نمی شود.
