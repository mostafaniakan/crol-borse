# روش امتیازدهی

در نسخه فعلی موتور امتیازدهی عملیاتی وجود ندارد و اعداد صفحه اصلی نمونه هستند. این سند قرارداد نسخه بعدی است.

Factors هدف: Value، Quality، Profitability، Growth، Momentum، Liquidity و Risk.

برای هر factor باید تعریف اقتصادی، فرمول، دوره، تاریخ دسترس پذیری، واحد، روش missing data، winsorization/robust scaling، جهت مطلوب، وزن و نتیجه آزمون ثبت شود. وزن ۳۰/۲۵/۲۰/۱۰/۱۵ تنظیم اولیه است و تا زمان آزمون تاریخی نباید به عنوان وزن معتبر معرفی شود.

رتبه فقط برای نماد واجد شرایط با Coverage و Calculation Trace کامل منتشر می شود. داده ناقص صفر نمی شود و وزن ها خودکار تغییر نمی کنند.
